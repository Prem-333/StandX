# Raw public metadata

`bis/` contains 20 manually selected public metadata HTML snapshots and provenance sidecars, captured after access-policy checks. These are catalogue metadata pages, not standards PDFs. Their exact URLs and UTC capture timestamps are in the sidecars and `docs/SOURCES.md`; the normalized records include SHA256 hashes. No live bulk collector exists. `mteb_*.json` archives official leaderboard responses used for the model comparison. User-supplied licensed full text still requires a separately authorized ingestion path.
